# 02 Agent 架构与总体流程

## 1. 总体架构

```text
                    用户
                     │
                 上传教材
                     ↓
              教材解析 / 索引
                     ↓
          ┌────────────────────┐
          │ 教材理解 Agent     │
          │ 大纲 / 知识结构提取 │
          └────────────────────┘
                     ↓
            Learning Blueprint
                     ↓
          ┌────────────────────┐
          │ 课程编排 Agent      │
          └────────────────────┘
             ↓   ↓   ↓   ↓
          讲解  拓展  交互  测验
             \   |   |   /
                审核
                  ↓
              内容整合
                  ↓
              在线文档
```

## 2. Agent 职责

### 教材理解 Agent

负责理解一本或多本教材，提取章节结构、知识单元及其关系，形成 Learning Blueprint。

### 课程编排 Agent

根据学习蓝图决定学习内容的组织方式，并调用其他 Agent 完成具体内容。

### 讲解生成 Agent

围绕指定知识单元生成学习者可直接阅读的讲解。

### 背景补充 Agent

在教材内容不足以支持理解时补充必要背景、应用或相关知识。

### 交互内容 Agent

识别适合数字化交互的内容，并生成相应交互模块。

### 测验生成 Agent

根据知识单元和学习内容生成练习与测试。

### 审核 Agent

检查内容的正确性、完整性以及与教材知识体系的一致性。

## 3. Agent Loop

项目重点练习以下几类 loop：

- 调研型：搜索、比较、补充、再检查
- 反思型：生成、评价、修改
- 执行反馈型：生成、执行、读取结果、修改
- 编排型：规划、委派、验收

具体每个 Agent 是否使用 loop，以及 loop 的停止条件，不在本策划书中固定。

## 4. 总体原则

Agent 数量不作为项目目标。只有在任务需要独立判断、工具调用或迭代反馈时才引入 Agent loop。

后续实现过程中可以根据实际效果合并或删除 Agent。
