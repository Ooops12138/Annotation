# 04 学习内容生成流程

## 1. 目标

基于 Learning Blueprint，将教材知识转化为在线学习内容。

## 2. 基本流程

```text
Learning Blueprint
      ↓
学习路径与内容规划
      ↓
知识单元讲解
      ↓
例题 / 证明 / 应用
      ↓
补充内容
      ↓
交互 / 图表 / 测验
      ↓
审核
      ↓
整合为在线文档
```

## 3. 核心讲解

讲解应以教材为主要依据，同时针对在线学习场景重新组织表达。

内容可以使用教材提供的教学组织、例子选择、论证路径等信息，并结合学习者需求进行解释和衔接。

## 4. 补充内容

补充内容用于解决教材学习过程中出现的信息缺口，例如：

- 背景概念
- 前置知识
- 应用场景
- 术语解释
- 教材之外的直观解释

补充内容应与知识蓝图中的具体知识单元建立关系。

## 5. 数字化内容

适合在线场景的内容可以进一步转化为：

- 图片 / 图表
- 可视化
- 交互组件
- 测验
- 练习

Agent 根据知识特点决定是否生成，不要求每个知识点都具备所有形式。

## 6. 内容整合

最终文档应保留统一的学习路径，使文本、例题、图表、交互和测验围绕同一知识结构组织。

具体页面结构、组件规范和前端实现属于后续设计。
