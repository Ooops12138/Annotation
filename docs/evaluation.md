# Annotation 评估与验收方案

## 1. 评估目的

评估不是只判断文本是否通顺，而是判断系统是否真正理解教材并把它转化为完整、正确、可追溯、适合在线学习的内容。第一阶段采用小规模、可重复的人工与自动混合评估。

## 2. 评估对象

固定一个学科的一章作为 POC 样本，建立以下基线材料：

- 授权的原始教材及章节定位；
- 人工整理的章节知识单元清单；
- 关键前置关系和教学顺序；
- 必须出现的定义、公式、定理、例题、证明或应用；
- 预先标注的高风险事实、易混概念和可能存在的学术分歧；
- 一组用于回归的代表性问答/测验目标。

评估样本应覆盖核心概念、边界情况、跨节依赖和至少一个需要补充背景的知识点，而不是只抽查最容易的段落。

## 3. 质量维度与评分

采用 0–4 分 rubric，并记录证据、来源和问题类型：

| 维度 | 0 分 | 2 分 | 4 分 |
|---|---|---|---|
| 蓝图覆盖 | 关键结构缺失 | 覆盖大部分但有明显遗漏 | 关键单元、材料和章节关系完整 |
| 蓝图关系 | 依赖错误或不可用 | 主路径基本可用但有错漏 | 前置、相关和学习顺序合理 |
| 内容正确性 | 有严重事实/逻辑错误 | 有可修正错误或未决点 | 核心事实、公式、推理可靠且有依据 |
| 教材一致性 | 改变主线或混淆来源 | 大体一致但补充边界不清 | 主教材骨架清楚，补充和冲突有标记 |
| 学习完整性 | 无法形成学习路径 | 可读但衔接或前置不足 | 解释、例题、证明、练习形成闭环 |
| 测验覆盖 | 与目标无关或有错误 | 覆盖部分核心知识 | 测验可追溯且覆盖核心目标 |
| 在线学习适配 | 只是原文拼接 | 有部分重组但体验不稳定 | 结构、分段、图表/交互和复习路径清晰 |
| 可追溯与风险标注 | 无来源或静默错误 | 部分内容可追踪 | 关键内容和审核风险均可定位 |

评分必须附带问题清单；平均分不能抵消阻塞性错误。

## 4. 自动检查

第一阶段只要求低成本、可解释的检查：

- 蓝图中的关键知识单元是否在最终文档中出现；
- 每个关键定义、公式、例题和测验是否存在来源或蓝图关联；
- 前置单元是否在使用它们的单元之前出现或被显式说明；
- 主教材、补充教材和外部资料标签是否完整；
- 内容 artifact、审核记录和最终页面是否能通过 ID/版本关联；
- 是否存在未处理的阻塞问题、孤立补充内容或未标注的不确定表述；
- 测验是否覆盖预先定义的学习目标。

自动检查用于发现遗漏和结构错误，不能单独证明数学推理或学术事实正确。

## 5. 人工审核流程

1. 一名熟悉该章节的评审者对蓝图逐单元检查覆盖、类型、来源和依赖。
2. 对讲解、例题、证明/推导、补充和测验按 rubric 评分并记录证据。
3. 对自动检查发现的问题进行确认、驳回或升级。
4. 对高风险或存在分歧的表述检查是否有明确标注，且没有替用户强行下结论。
5. 记录修改建议，重生成后保留原版本并复评受影响部分。

若条件允许，再由第二位评审者抽查高风险项，比较分歧并修订 rubric。

## 6. 第一阶段发布门槛

一个章节只有同时满足以下条件，才算 POC 通过：

- 蓝图覆盖和关系检查无未解释的关键遗漏；
- 核心定义、公式、定理和推理不存在未标记的严重错误；
- 每个关键学习目标都有讲解或可解释的覆盖关系；
- 测验覆盖核心知识，且错误题目已阻塞发布；
- 关键内容可追溯到教材或明确标记的补充来源；
- 审核问题已关闭、带风险发布或交由人工，不存在静默失败；
- 在线文档的学习路径比原始章节直接阅读更清晰，至少在人工评审中得到支持。

建议将“内容正确性”和“可追溯与风险标注”视为硬门槛，其余维度使用阶段性目标，不用一个总分掩盖硬错误。

## 7. 错误分类与回归

统一记录：解析/定位错误、蓝图遗漏、错误合并、依赖错误、事实错误、逻辑错误、公式/定义错误、教材冲突、来源丢失、测验错配、呈现问题和审核误判。

每个已修复的高风险问题都应加入最小回归样本，确保后续 prompt、模型、解析器或编排变更不会重新引入。评估结果保存运行标识、输入版本、配置/模型版本和输出版本。

## 8. 后续扩展

POC 稳定后再考虑：学习者行为反馈、自动难度估计、多评审者一致性、跨学科基准、多教材冲突指标、长程回归集和更复杂的自动事实核查。
