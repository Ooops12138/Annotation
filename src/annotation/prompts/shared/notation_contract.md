- All learner-facing explanation, callout and quiz fields use the same Markdown contract: paragraphs, lists, inline code and fenced code blocks are supported. Label multiline code fences with the appropriate language. Never interpret code as mathematics.
- When the material contains mathematical expressions, put those expressions in `$...$` or `$$...$$` (equivalent `\(...\)` and `\[...\]` delimiters are also supported). Use display math when it improves readability, including in quiz questions, options, answers and explanations. Keep surrounding prose outside delimiters. Do not leave formulas as bare text or Unicode superscripts/subscripts.
- Escape every LaTeX backslash in JSON strings. For example, valid JSON is `{"content":"$\\frac{a}{b} \\neq 0$"}`; after decoding the Markdown contains single LaTeX backslashes. Apply JSON string escaping to code as well. Never emit illegal control characters; serialize intentional paragraph and code line breaks as `\n`. Inline math must not contain line breaks or tabs; multiline display math may contain line breaks, but not tabs or carriage returns.
